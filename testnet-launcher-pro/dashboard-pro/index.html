How to join the KASCompute testnet

Download the community scripts and run a node + miner in minutes. Your node identity is auto-generated on first launch (persistent identity.json).

Recommended
Fastest path: run node + miner

This mirrors mainnet behaviour: the node maintains presence (heartbeats), the miner executes compute jobs and submits proofs for KCT rewards.

  • Install PowerShell 7 (required)
  • Download the pack and unzip into one folder
  • Run start_all_pro.ps1 (opens 2 windows)
Run
Right click → Run with PowerShell
or inside pwsh:

pwsh -ExecutionPolicy Bypass -File .\start_all_pro.ps1
First run auto-creates identity.json (node_id + key). Keep it to preserve your identity.
Option 1
Run a KASCompute node

Your node sends heartbeats to the orchestrator and appears on the map and node list (GeoIP when available).

  • Run start_node_pro.ps1
  • Keep the window open to stay online
  • Node identity is stored in identity.json
Download start_node_pro.ps1
Option 2
Start mining (compute + proofs)

The miner requests jobs, performs compute, submits proofs and participates in fair reward distribution. Hash mode is treated as verified compute (bonus).

  • Start your node first (recommended)
  • Run start_miner_pro.ps1
  • Workload toggle via kascompute_env.ps1
Workload mode
# inside kascompute_env.ps1
WORKLOAD_MODE="sim"   # lightweight demo
WORKLOAD_MODE="hash"  # real CPU work (verified)
Download start_miner_pro.ps1
